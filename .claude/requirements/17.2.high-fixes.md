Fix all 9 HIGH priority issues identified in the codebase audit (`.claude/notes/2026-03-20-6.md`, v0.17.0).

These are data-corruption edge cases, security vulnerabilities, and bugs:

6. Device key rotation lacks transaction semantics — if re-encryption fails partway, new key is active but old-key data is unreadable (SecuritySettingsModal.tsx)
7. reencryptJournal has no try-catch for partial failures — mixed encryption keys with no recovery (JournalSettings.tsx)
8. Malformed ZIP attachments skipped silently — corrupted backups lose attachments without user notification (import.ts, import.web.ts)
9. existingIds prop never wired — cloud import "already local" detection is broken (NewJournalModal.tsx, app/index.tsx)
10. Device encryption key stored in unencrypted localStorage — XSS can steal key and decrypt all data (device.web.ts)
11. Auto-lock interval accumulates — missing cleanup on clearAll dependency change (JournalKeyContext.tsx)
12. downloadPageAttachments silently skips null attachments — pages left with stale remote paths (engine.ts)
13. deserializePages casts JSON.parse directly to Page without validation — silent corruption on import (format.ts)
14. Untracked promise in scheduleSyncDebounced — stale manager after unmount causes silent failures (SyncManagerContext.tsx)
