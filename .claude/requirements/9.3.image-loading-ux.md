# 9.3 Image Loading UX & Journal Creation Redirect

## Issues

1. **Image loading blocks UI**: Loading images (thumbnails in journal list, images in page view) blocks the UI thread. If user taps back, even the home screen is frozen until all pending image loads complete.

2. **Journal creation redirects to "not found"**: After creating a journal, user sees "Journal not found" page instead of the new journal. Redirect to homepage instead.

3. **Image loading performance**: All images load simultaneously with no concurrency control. Need a queue to limit concurrent loads and preserve device resources.
