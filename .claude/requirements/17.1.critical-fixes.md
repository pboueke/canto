Fix all 5 CRITICAL issues identified in the codebase audit (`.claude/notes/2026-03-20-6.md`, v0.17.0).

These are data-corruption risks that can occur in normal usage:

1. Race condition in store initialization — concurrent `ensureInitialized()` calls can create multiple store instances (useStorage.ts)
2. Race condition in device key creation — no mutex around `getOrCreateDeviceKey()` (device.ts)
3. `Promise.allSettled()` silently drops failed page downloads during sync (gdrive/store.ts)
4. No error handling around `saveAttachment()` during import — partial failure leaves orphaned data (import.ts)
5. `checkNumber()` accepts NaN and Infinity — corrupts data on JSON round-trip (validation.ts)
