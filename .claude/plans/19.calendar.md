# Plan 19 — Per-journal Calendar page + anniversary filter

## Goals (from requirement)

1. New journal filter: **anniversary** — shows pages whose month+day matches today, from _previous years only_.
2. New **calendar button** in `JournalHeader` (left of remote sync) opens a per-journal calendar page.
3. **Calendar page** contains:
   - Header `'{Journal title} Calendar'`
   - Anniversary row: `"N pages celebrating anniversaries today"` (0-aware copy). Tapping it → journal with anniversary filter on.
   - Scroll of month previews (only months containing pages), with days-with-pages highlighted.
   - Tapping a month preview → journal filtered to that month's date range.
4. **Scroll state preserved** across in-session navigation (calendar ↔ journal ↔ page). Not persisted to storage.

## Decisions

- **Route layout**: restructure `app/journal/[id].tsx` → `app/journal/[id]/index.tsx`, add `app/journal/[id]/calendar.tsx`. Expo Router still resolves `/journal/{id}` to the index. Sibling route keeps URLs clean and matches the existing folder-per-section pattern (see `app/`).
- **Anniversary filter storage**: kept client-side in `useFilter` as a new boolean property. `canto-data`'s `Filter` type is not modified — we extend the hook's state only, since the anniversary concept is presentation-layer.
- **Cross-page filter handoff**: URL search params on `/journal/{id}` are read once on mount to seed `useFilter`. Three new params: `anniversary=1`, `dateStart=<iso>`, `dateEnd=<iso>`.
- **Scroll preservation**: a new `CalendarScrollContext` (at `app/_layout.tsx` level) storing `{ [journalId]: number }`. The calendar page reads the offset on mount and writes on scroll. Resets only when the app reloads — session-scoped as requested.
- **Month preview library**: hand-rolled small grid (7×6) in a `MonthPreview` component — avoids pulling in a date-picker for a read-only view and keeps bundle size flat. Date math uses the existing `Date` stdlib (journal is already using it throughout).

## UX details

- **Calendar button placement**: leftmost in `actions` row, before sync. Feather `calendar` icon, same 20px size as siblings.
- **Anniversary row**: full-width, primary color background when count > 0, muted surface + disabled press when 0. Icon: `gift`.
- **Month preview**: ~7 columns × 6 rows grid. Day number centered; if that day has ≥1 page, render a filled circle behind the number in `theme.colors.primary`. Month/year label on top. Entire card is a `Pressable`.
- **Empty state**: if no pages at all, show `CalendarHeader` + centered `"No pages yet"` text.

### `src/lib/__tests__/calendar.test.ts`

`getAnniversaryPages(pages, today)`:

- Includes prior-year same month+day pages (e.g. today = 2026-04-14 returns pages dated 2025-04-14, 2024-04-14).
- Excludes current-year matches (2026-04-14 page is not an anniversary of itself).
- Excludes same-day-different-month and same-month-different-day pages.
- Respects time-of-day: a 2025-04-14T23:59:59Z page is still an anniversary when today is 2026-04-14T00:00:01Z (compare by UTC Y/M/D, not timestamp).
- Feb-29 edge: today = 2024-02-29 returns only pages dated YYYY-02-29 (prior leap years); today = 2025-02-28 does **not** surface Feb-29 pages (document decision in a code comment).
- Handles timezone crossover: page dated 2025-04-14T00:30:00+05:00 (= 2025-04-13T19:30:00Z) is treated as the UTC day 2025-04-13, matching the same UTC rules the existing date filter uses (`useFilter.ts:34-44`).
- Empty input returns `[]`.
- Ignores pages with malformed dates (defensive — returns them filtered out, doesn't throw).

`getMonthsWithPages(pages, sort)`:

- Returns one entry per (year, month) that has ≥1 page; no empty months in between.
- `daysWithPages` is a `Set<number>` of 1–31 numbers containing every day that has ≥1 page that month.
- Multiple pages on the same day collapse to a single entry in `daysWithPages`.
- `sort: 'ascending'` returns oldest month first; `'descending'` newest first; default (undefined) matches descending.
- Pages with `deleted: true` are excluded (mirrors the journal screen's filter).
- Cross-year grouping: pages in 2024-12 and 2025-01 are two distinct entries.

`monthRange(year, month)`:

- January: start = `2026-01-01T00:00:00.000Z`, end = `2026-01-31T23:59:59.999Z`.
- December: start = `2026-12-01T00:00:00.000Z`, end = `2026-12-31T23:59:59.999Z`.
- February leap year (2024) → end day = 29; February non-leap (2025) → end day = 28.
- 30-day month (April) → end day = 30.
- Returned ISO strings round-trip through `new Date()` without drift (spot-check `new Date(range.end).getUTCMonth() === month`).
