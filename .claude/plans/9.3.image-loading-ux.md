# Plan: 9.3 Image Loading UX & Journal Creation Redirect

## Analysis

### Issue 1: Image loading blocks UI

- `PageListItem` thumbnails all load simultaneously via `useEffect` on mount
- `ImageCarousel` fires all image loads at once in `useEffect` (line 63-67)
- AES-GCM decryption + file I/O on the JS thread blocks navigation animations
- When user taps back, pending decryption operations prevent the home screen from rendering

### Issue 2: Journal creation → "not found"

- After `handleCreate` in `index.tsx`, the app pushes to `/journal/${journalId}`
- The journal screen shows "Journal not found" if `!journal` after loading
- Likely a race condition between key caching and journal screen's initial render
- Fix: replace the static "not found" text with a redirect to home via `router.replace('/')`

### Issue 3: Image loading performance

- No concurrency control — all images fire simultaneously
- Each image involves: file read → device decrypt → optional password decrypt → base64 encode
- With many images, this saturates the JS thread

## Implementation

### Step 1: Create `useImageQueue` hook

**New file**: `src/hooks/useImageQueue.ts`

- Concurrency-limited async queue (max 2 concurrent loads)
- Supports cancellation via AbortController-like pattern
- Uses `InteractionManager.runAfterInteractions` to defer loading until after navigation animations complete
- Returns `{ loadedImages, loadingImages, enqueue, cancelAll }`

### Step 2: Update `ImageCarousel` to use queue

**File**: `src/components/page/ImageCarousel.tsx`

- Replace direct `loadImageData` calls with queue-based loading
- Cancel all pending loads on unmount
- Only load visible + adjacent images (keep current behavior but through queue)

### Step 3: Update `PageListItem` to use queue

**File**: `src/components/journal/PageListItem.tsx`

- Use `InteractionManager.runAfterInteractions` before starting thumbnail load
- Cancel on unmount to prevent stale updates and free up the queue

### Step 4: Fix journal "not found" redirect

**File**: `app/journal/[id].tsx`

- When `!journal && !loading`, use `router.replace('/')` to redirect to homepage
- Use `useEffect` to trigger the redirect to avoid render-time side effects
