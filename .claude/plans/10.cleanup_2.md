Current config only uses `@typescript-eslint/recommended`. Add rules that enforce better TypeScript style:

- `@typescript-eslint/explicit-function-return-type` — warn for exported functions (improves readability)
- `@typescript-eslint/no-explicit-any` — error (already in recommended but confirm it's active)
- `@typescript-eslint/consistent-type-imports` — warn (use `import type` where possible, reduces bundle)
- `no-console` — warn (prevent accidental console.log in production)
