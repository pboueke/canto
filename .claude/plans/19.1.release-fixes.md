# Plan 19.1 — Release Fixes

Five independent UX / robustness fixes from `19.1.release-fixes.md`. Each is small and can ship in one PR, but they share a release-cut goal so are bundled here.

## Decisions (resolved with user)

- **Font sizes**: four presets with multipliers `0.85 / 1.0 / 1.15 / 1.3` (small / default / large / x-large).
- **Font family**: three options — `default` (current Lato + Merriweather pair), `dyslexic` (OpenDyslexic), `serif` (Lora as primary). Lora is OFL-licensed and pairs well with Merriweather as fallback for bold/italic until those weights are added.
- **Font scope**: app-wide only (no per-journal override). Stored in AsyncStorage alongside `canto:theme` / `canto:lang`.
- **GDrive retry**: implemented inside `executeCloudImport`'s per-page loop. 5 total attempts per page, exponential backoff `1s → 2s → 4s → 8s`. Wraps the full pipeline (download + decrypt + attachments), not the transport.
- **GDrive load modal**: new `'preparing'` phase shown immediately when a journal is tapped, covering the gap before page downloads start (connect / downloadMeta / keyDerive / downloadSyncIndex). Existing per-page progress UI is preserved.
- **Editor keyboard fix**: wrap the page `ScrollView` in `KeyboardAvoidingView` and scroll the caret line into view on `onSelectionChange` / `onContentSizeChange`.
- **Decrypting copy**: new `t.home.decrypting` key, populated for all 21 languages (reusing existing per-locale "Decrypting..." translations that already exist for `t.page.decrypting`).

## Issue 4 — Per-page retry on gdrive import (5 attempts, exponential backoff)

### Goals

- Each page download in `executeCloudImport` is retried up to 4 times after the first failure (5 total attempts) before being recorded as a failure.
- Backoff: `1s, 2s, 4s, 8s`.
- Retry wraps the whole per-page pipeline: `downloadPage` + `aesGcmDecrypt` + `safeJsonParse` + per-attachment downloads.
- Existing `fetchWithRetry` (api.ts line 29–42) is left in place — it handles transport-level transient errors and is orthogonal.

### Files

**New**

- `src/lib/sync/retry.ts`:
  - `retryWithBackoff<T>(fn: () => Promise<T>, opts: { attempts: number; delaysMs: number[]; onAttempt?: (n: number, err: unknown) => void }): Promise<T>`
  - Returns the result of the last successful call or throws the last error.

**Modified**

- `src/components/home/NewJournalModal.tsx` — extract the body of the existing per-page `for` loop (lines 239–281) into an inline `async function downloadOnePage(pageId)` (or call site) and wrap with `retryWithBackoff`. On final failure, record into `downloadFailures` exactly as today; on success, push to `journal.pages` and advance `current`.
- Add `console.warn('[Canto] Cloud import page retry', { pageId, attempt, err })` in `onAttempt` so the integrity warning details are debuggable.
- (Optional, agreed: NO) — do NOT add retry to `executeCloudImport`'s top-level meta/syncIndex downloads. The requirement is per-page. Meta failure aborts the whole import as today.

### Tests

- `src/lib/sync/__tests__/retry.test.ts` — `retryWithBackoff` succeeds on attempts 1/2/5, throws after 5, calls `onAttempt` correctly, respects `delaysMs` (use fake timers).
- `src/components/home/__tests__/NewJournalModal.retry.test.tsx` — mock `downloadPage` to fail 4× then succeed on the 5th; assert page ends up in `journal.pages` and no `downloadFailure` recorded.

## Cross-cutting

### Order of work (smallest blast-radius first)

1. **Issue 2** (decrypting copy) — 1 i18n key + 1 line edit. Smoke test.

5. **Issue 1** (fonts) — biggest diff (i18n × 21 locales, font assets, layout changes). Ship last.

### Pre-commit / CI

- All five issues run through existing Husky lint-staged hooks (eslint + prettier).
- `npm test` must pass.
- TypeScript strict still clean.

### Changelog + notes

- Bump version in `package.json` and `CHANGELOG.md` once all five are merged (single entry: "v0.19.1 — release fixes").
- Add `.claude/notes/{date}-1.md` summarizing decisions + any deviations.

### Risk register

- **Lora bold/italic**: if Lora-Bold/Italic .ttf are not shipped, Merriweather-Bold falls through. Verify rendering on Android (where font fallback is stricter than iOS).
- **OpenDyslexic line-height**: noticeably taller. Confirm calendar / journal-card layouts don't clip at `large` + `dyslexic`. If clipping, scale `lineHeight` proportionally in `themes.ts`.
- **KeyboardAvoidingView on Android**: requires `adjustResize`. If currently set to `adjustPan`, switching may affect other screens — spot-check `JournalAccessModal`, `CommentModal`, `NewJournalModal` input flows.
- **GDrive retry timing**: 5 attempts × 8s max backoff = ~15s worst-case delay per page on a flaky network. For a 100-page journal, that's a real ceiling. Acceptable per requirement; surface in retry log so users with slow imports can see _why_ it's slow.
