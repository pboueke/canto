# Plan 13: Sync, Encryption & Storage Review Fixes

## Context

Code review of `src/lib/{sync,encryption,storage}` identified 4 critical, 8 high, and 8 medium severity issues across correctness, security, and reliability.

---

## Phase 1 — Critical Bugs (correctness)

### 1.1 Fix `syncAll()` dropping `derivedKey`

- **File:** `src/lib/sync/engine.ts:163`
- **Problem:** `this.sync(journal.id)` called without `derivedKey` — encrypted journals silently fail
- **Fix:** Thread `derivedKey` map or per-journal key lookup through `syncAll()`

### 1.2 Fix inverted cache clearing in `connect()`

- **File:** `src/lib/sync/gdrive/store.ts:42-47`
- **Problem:** Cache clears when token is unchanged (no-op); doesn't clear when token changes
- **Fix:** Invert condition: clear cache when `tokenChanged === true`

### 1.3 Fix `parallel()` worker race condition

- **File:** `src/lib/sync/engine.ts:13-19`
- **Problem:** Shared `let i = 0` counter across async workers can cause index reuse after `await` yields
- **Fix:** Replace with pre-partitioned chunks or a queue that pops atomically before `await`

### 1.4 Wire up configurable KDF iterations

- **File:** `src/lib/encryption/password.ts`
- **Problem:** `encrypt()`/`decrypt()` hardcode `LEGACY_KDF_ITERATIONS` (20k) despite exporting stronger presets
- **Fix:** Accept `iterations` parameter, default to `DEFAULT_KDF_ITERATIONS` (50k), store iteration count in ciphertext envelope so `decrypt()` can read it back

## Phase 2 — High Severity (security & reliability)

### 2.1 Escape values in Drive API queries

- **Files:** `src/lib/sync/gdrive/store.ts:70,109-111,157-159,236,319`
- **Problem:** Journal IDs and filenames interpolated directly into ODATA query strings
- **Fix:** Add `escapeQueryValue()` helper that escapes single quotes and backslashes; apply to all query string interpolations

### 2.2 Fix silent attachment upload failure

- **File:** `src/lib/sync/engine.ts:44-47`
- **Problem:** Null attachment data silently skipped — synced pages reference missing attachments
- **Fix:** Log warning and include in sync result errors; optionally mark page sync as partial failure

### 2.3 Fix `deleteJournal()` operation order

- **File:** `src/lib/storage/local.ts:262-272`
- **Problem:** Removes from index first, then deletes directory — orphans data if dir delete fails
- **Fix:** Delete directory first; only update index on success

### 2.4 Add attachment re-encryption

- **File:** `src/lib/storage/local.ts:370-378`
- **Problem:** `reencryptJournal()` re-encrypts pages but skips attachments entirely
- **Fix:** Iterate attachment directory and re-encrypt each file with new key

### 2.5 Fix rate limiter race condition

- **File:** `src/lib/encryption/ratelimit.ts`
- **Problem:** Concurrent `attempt()` calls both read same state, bypassing backoff
- **Fix:** Add in-memory mutex (simple promise chain) around `loadState()`/`saveState()` cycle

### 2.6 Surface errors from debounced sync

- **File:** `src/lib/sync/manager.ts:115`
- **Problem:** `syncJournal()` promise inside `setTimeout` is fire-and-forget
- **Fix:** Catch and route errors to state/listeners so UI can display sync failures

### 2.7 Prevent duplicate folder creation

- **File:** `src/lib/sync/gdrive/store.ts:103-128`
- **Problem:** Concurrent `getOrCreateFolder()` calls both miss cache, both create
- **Fix:** Add per-key in-flight promise dedup (if creation is already pending for `name+parentId`, await existing promise)

### 2.8 Sanitize error messages

- **File:** `src/lib/sync/gdrive/api.ts:24,30,67`
- **Problem:** API responses may contain tokens or sensitive data in error strings
- **Fix:** Strip or redact response bodies in thrown errors; keep status code and a generic message

## Phase 3 — Medium Severity (robustness)

### 3.1 Use `Promise.allSettled()` for page downloads

- **File:** `src/lib/sync/gdrive/store.ts:240-245`
- **Fix:** Replace `Promise.all()` with `Promise.allSettled()`, return successfully parsed pages and collect errors

### 3.2 Fix `deleteJournal()` cache purge

- **File:** `src/lib/sync/gdrive/store.ts:302-324`
- **Fix:** Use exact prefix match (`key.startsWith(journalId + '/')`) instead of `includes()`

### 3.3 Validate base64 input in `base64ToUint8()`

- **File:** `src/lib/encryption/utils.ts:122-124`
- **Fix:** Check for invalid characters (lookup === 255) and throw instead of silently corrupting

### 3.4 Add thread yield to byte-level crypto functions

- **File:** `src/lib/encryption/utils.ts`
- **Fix:** Add `await yieldThread()` in `aesGcmEncryptBytes()` and `aesGcmDecryptBytes()` to match string variants

### 3.5 Validate JSON parse results at storage boundaries

- **Files:** `src/lib/storage/local.ts:161,195,206`
- **Fix:** Add lightweight runtime type checks after `JSON.parse()` before casting with `as`

### 3.6 Add basic retry for transient Drive API errors

- **File:** `src/lib/sync/gdrive/api.ts`
- **Fix:** Retry once on 5xx / network errors with short backoff; no retry on 4xx

### 3.7 Validate AES key size before import

- **File:** `src/lib/encryption/utils.ts`
- **Fix:** Assert key is 32 bytes at the top of encrypt/decrypt functions

### 3.8 Improve `readEncrypted()` error discrimination

- **File:** `src/lib/storage/local.ts:88-91`
- **Fix:** Distinguish file-not-found (return null) from decryption failure (throw or return tagged error)
