## Task 1: Fix Portuguese translations — missing diacritics

**Problem:** The entire Portuguese dictionary (except `onboarding`) is missing accents and special characters. E.g. "Configuracoes" should be "Configurações", "diario" → "diário", "nao" → "não", "pagina" → "página", etc. The `langNativeNames` entry is also wrong: "Portugues" → "Português".

**Fix** in `src/i18n/dictionaries.ts`:

- Fix `langNativeNames.pt` to `'Português'`
- Also fix `langNativeNames.es` to `'Español'` and `langNativeNames.fr` to `'Français'` (same issue)
- Go through the entire `pt` dictionary (lines ~537–807) and add proper diacritics to every string: ã, õ, ç, é, ê, á, à, ó, ô, ú, í
- The `onboarding` section (lines ~760–774) already has correct diacritics — use it as reference for tone/style
- Also audit `es` (Spanish) for missing ñ, á, é, í, ó, ú, ¿, ¡ and `fr` (French) for missing é, è, ê, ë, ç, à, ù, î, ô, û, æ, œ

**Test:** Existing `src/i18n/__tests__/dictionaries.test.ts` validates key structure — should still pass. No new test needed.

## Task 2: Fix carousel image centering on web

**Problem:** On web, images align to the right of their carousel item instead of being centered.

**Root cause:** The `imageWrapper` style (line 225) has `position: 'relative'` and fixed `height`/`width` but no flex centering. On web, `resizeMode="contain"` doesn't auto-center the image element within its parent.

**Fix** in `src/components/page/ImageCarousel.tsx`:

- Add `alignItems: 'center'` and `justifyContent: 'center'` to the `imageWrapper` style

**Test:** Add/update test in `src/components/page/__tests__/ImageCarousel.test.tsx` verifying the image wrapper has centering styles applied.

## Task 3: Fix download button visibility on web

**Problem:** The download button is invisible on web. It uses `theme.colors.surface` background which blends with the image.

**Fix** in `src/components/page/ImageCarousel.tsx`:

- Change download button background to semi-transparent dark: `rgba(0, 0, 0, 0.4)`
- Change icon color to white (`#fff`) instead of `theme.colors.text`
- Increase button size to 36px for better visibility and touch target

**Test:** Add/update test verifying download button renders with correct styling when `editable=false` and `onDownload` is provided.
