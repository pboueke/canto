# Plan: Styling & Navigation (Requirement 2)

## Goal

Replicate the original Canto app's visual identity and navigation structure in the new Expo Router codebase. Add static assets, implement the home page with matching color schemes, build navigation components, and create mock data so all screens are navigable.

## Current State

- Expo Router screens exist as minimal placeholders: `index.tsx`, `journal/[id].tsx`, `page/[id].tsx`
- Theme system exists (`src/styles/themes.ts`) with light/dark themes but colors don't match the original app
- Component directories exist but are empty (`src/components/{common,home,journal,page}/`)
- i18n and theme hooks are functional
- No static assets (logos, images) exist yet

## Reference App Analysis

**Original color scheme (light):**

- Text: `rgb(0,0,0)`, Links: `rgb(1,85,92)` (dark teal)
- Background: `rgb(190,190,190)`, Foreground: `rgb(255,255,255)`
- Borders: `rgb(0,0,0)` 2px solid, border-radius 5px
- Edit bar: `rgb(232,202,51)` (gold), Delete: `rgb(255,109,5)` (orange)
- Tags: border-radius 20px, teal/orange accents

**Original color scheme (dark):**

- Text: `rgb(222,222,222)`, Links: `rgb(255,161,186)` (pink)
- Background: `rgb(0,0,0)`, Foreground: `rgb(40,40,40)`
- Borders: `rgb(100,100,100)` 1px solid
- Success: `rgb(54,245,168)`, Failure: `rgb(255,109,5)`

**Fonts:** Lato (UI/menus), Merriweather (body/content text)

**Navigation:** Home → Journal (page list) → Page (entry editor)

**Home page layout:** Two-column — logo left, info box right (theme/lang toggles, about, version), journal cards below

## Steps

### Step 1: Copy static assets from reference repo

- Copy logo files from `~/Repositories/copy/canto/src/assets/images/` to `src/assets/images/`:
  - `canto_bv1.svg`, `canto_wv1.svg` (dark/white SVG logos)
  - `canto_bv1.png` (dark PNG logo)
  - `canto_banner_v1.png` (banner)
  - `logo_t_v1_256.png` (app icon/favicon)
- Install `react-native-svg` and `react-native-svg-transformer` if not already present for SVG rendering
- Verify assets load correctly

### Step 2: Update theme to match original color scheme

Update `src/styles/themes.ts` to match the reference app's exact colors:

**Light theme updates:**

- primary → `rgb(1, 85, 92)` (teal links)
- background → `rgb(190, 190, 190)` (gray)
- surface/foreground → `rgb(255, 255, 255)` (white)
- text → `rgb(0, 0, 0)`
- border → `rgb(0, 0, 0)`, borderWidth: 2
- accent/editBar → `rgb(232, 202, 51)` (gold)
- danger/delete → `rgb(255, 109, 5)` (orange)
- tagAdd → `rgb(237, 162, 71)`, tagRemove → `rgb(87, 196, 173)`

**Dark theme updates:**

- primary → `rgb(255, 161, 186)` (pink links)
- background → `rgb(0, 0, 0)`
- surface/foreground → `rgb(40, 40, 40)`
- text → `rgb(222, 222, 222)`
- border → `rgb(100, 100, 100)`, borderWidth: 1
- success → `rgb(54, 245, 168)`, failure → `rgb(255, 109, 5)`
- journal cards → `rgb(50, 50, 50)`

Add theme properties for: `borderWidth`, `highlight`, `cardBackground`, `editBar`, `deleteAction`, `tagAdd`, `tagRemove`.

### Step 3: Install fonts (Lato + Merriweather)

- Use `expo-font` (already installed) to load Lato and Merriweather font families
- Download font files to `src/assets/fonts/`
- Load fonts in `_layout.tsx` using `useFonts` hook
- Show splash screen until fonts are loaded
- Update theme font references to use actual font names

### Step 4: Build common components

Create reusable components in `src/components/common/`:

- **Logo.tsx** — Theme-aware logo component (switches dark/white based on theme), configurable size (default 180px). Use PNG fallback initially; SVG if `react-native-svg` is configured.
- **FloatingActionButton.tsx** — Circular button (50px), positioned bottom-right or bottom-left, with icon and onPress handler. Matches original's `PopAction` pattern.
- **Tag.tsx** — Pill-shaped tag display (border-radius 20px, padding 2-5px), theme-colored.
- **Card.tsx** — Bordered card with theme background, border-radius 5px, elevation shadow.

### Step 5: Build home screen components

Create in `src/components/home/`:

- **InfoBox.tsx** — Right-side info panel with bordered box containing: theme toggle, language selector, about link, version display. Uses `highlight` theme color for background.
- **JournalCard.tsx** — Journal selector card showing journal name, icon, entry count. Tappable, navigates to `journal/[id]`. Uses `Card` base component.
- **NewJournalCard.tsx** — "Add new journal" card with + icon. Placeholder action for now.

### Step 11: Create mock data
