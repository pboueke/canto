# Plan: Credible Launch (v0.15.0)

Designed via `/office-hours` → `/plan-eng-review` → `/plan-design-review` session.

## Context

Canto is feature-complete at v0.14.x but not publicly available. Competitive reference is Journey (subscription bloat, unclear security, unencrypted data). Canto is the open-source, encrypted, no-subscription alternative.

Design doc: `~/.gstack/projects/pboueke-canto/pedro-master-design-20260320-114558.md`

## Approach: Credible Launch (chosen from 3 alternatives)

Ship to Google Play Store with trust signals for privacy-conscious audience: onboarding flow, security whitepaper, landing page.

## Architecture Decisions (from eng review)

1. Onboarding as separate Expo Router route (not inline in \_layout.tsx) — clean separation
2. Pre-commit hook reads each file's own version independently — prevents drift
3. versionCode auto-increments when versionName changes — Play Store requirement
4. Skip = done forever — no re-showing onboarding to users who skipped
