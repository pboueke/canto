# Plan: Requirement 7 — Journal Management (Settings + Filter Bar)

## Overview

Two major features for the journal screen:

1. **Journal Settings** — full-screen config panel opened via the cog icon
2. **Filter Bar** — horizontal bar with search, date range, attachment/tag filters

---

## Part A: Journal Settings Panel

### A1. New hook: `useDeleteJournal` + `useSaveJournalSettings`

**File:** `src/hooks/useStorage.ts`

- `useDeleteJournal()` — wraps `store.deleteJournal(id)`, clears the journal key from context, navigates back to home
- `useSaveJournalSettings(journalId, derivedKey)` — loads journal via `store.getJournal()`, mutates fields (title, icon, settings, salt/secure), saves via `store.saveJournal()`
- `useChangePassword(journalId)` — decrypts all pages + attachments with old key, re-encrypts with new key (or removes encryption), updates journal salt/secure flag. This is the most complex operation.

### A6. Re-encryption flow (change password)

This is the trickiest part. Steps:

1. Verify current password (if secure) by attempting to decrypt a page
2. Decrypt ALL pages with current key
3. Decrypt ALL encrypted attachments with current key
4. If new password provided: generate new salt, derive new key
5. Re-encrypt all pages with new key (or device-only encryption if no password)
6. Re-encrypt all encrypted attachments with new key
7. Update journal: `salt`, `secure` flag
8. Save everything via `store.saveJournal()` + `store.savePage()` for each page
9. Update the key cache in JournalKeyContext

Edge cases:

- If new password is blank → remove password protection (secure=false, no salt)
- If no current password → just add password protection
- Show progress (page X of Y)

## Part B: Filter Bar

### B1. Filter state management

**File:** `src/hooks/useFilter.ts`

Custom hook `useFilter(pages: PagePreview[])` that:

- Manages `Filter` state (from `src/models/types.ts` — already defined)
- Returns `{ filter, setQuery, setDateStart, setDateEnd, toggleProperty, toggleTag, clearFilters, filteredPages, isActive }`
- `filteredPages` applies all active filters to the input pages list:
  - **query**: case-insensitive match on `previewText`
  - **hasImage/hasFile/hasLocation**: check boolean flags on PagePreview
  - **hasComments**: need to add this to PagePreview (currently missing — add `hasComments: boolean` to the type and `pageToPreview`)
  - **tags**: entry must have ALL selected tags (AND logic, matching reference app)
  - **dateStart/dateEnd**: inclusive range on `page.date`
- Multiple filters combine with AND logic

### B2. Update PagePreview model

**File:** `src/models/types.ts`
