# 2026-03-12 - Repository Restructure (Requirement 1)

## What was done

Rebuilt the Canto repository from scratch with a modern stack:

### Framework

- **Expo SDK 55** with **TypeScript** (strict mode)
- **Expo Router** for file-based navigation
- Targets: Android, iOS, Web

### Project structure

- `app/` — Expo Router screens (\_layout, index, journal/[id], page/[id])
- `src/hooks/` — useTheme, useI18n custom hooks with React Context
- `src/styles/` — Light and dark theme definitions (matching original color scheme)
- `src/i18n/` — English and Portuguese dictionaries
- `__tests__/` — Unit tests for themes and dictionaries

### Tooling

- **ESLint** (flat config) + **Prettier** for linting/formatting
- **Jest** + **jest-expo** for testing (10 passing tests)
- **Husky** + **lint-staged** for pre-commit hooks
- **TypeScript** strict mode with path aliases (`@/`)

### Hello World app

- Home screen with app name, tagline, theme toggle, and language toggle
- Placeholder journal and page screens with dynamic routing
- StatusBar adapts to theme
- Preferences persisted with AsyncStorage

### Verified

- `npm run typecheck` — passes
- `npm run lint` — passes
- `npm test` — 10/10 tests pass
- `npx expo export --platform web` — builds successfully

### Notes

- Required `jest.setup.ts` to mock `__ExpoImportMetaRegistry` and `structuredClone` for Jest 30 + Expo SDK 55 compatibility
- Used `--legacy-peer-deps` for some npm installs due to peer dependency conflicts in the Expo ecosystem
- Removed `eslint-plugin-react` from ESLint config due to incompatibility with ESLint 10; using `@typescript-eslint` rules only
