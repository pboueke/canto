# Runtime fixes for journal creation (requirement 4 follow-up)

## Native module issues

### expo-crypto removal

`expo-crypto` native module `ExpoCryptoAES` was not available in the runtime (Expo Go / stale native build). Replaced all `getRandomBytes` calls in `device.ts` and `utils.ts` with `crypto.getRandomValues()` from the Web Crypto API.

### crypto polyfill

`crypto` global was not available in Hermes. Installed `react-native-get-random-values` as a CSPRNG polyfill — imported at the top of `app/_layout.tsx` before any other code. Uses `SecureRandom` (Android) / `SecRandomCopyBytes` (iOS) under the hood. No security compromise.

### UUID generation

Replaced `uuid` library (failed its own `crypto.getRandomValues` check) and `expo-crypto`'s `randomUUID` with an inline UUID v4 generator using `crypto.getRandomValues` directly.

## PBKDF2 performance

### Synchronous → async

`pbkdf2` from `@noble/hashes` was blocking the JS thread for the full 600k iterations. Switched to `pbkdf2Async` in both `JournalKeyContext.tsx` and `password.ts` — yields to the event loop periodically.

### Iteration count: 600k → 20k

600k iterations (OWASP server-side recommendation) was far too slow in pure JS on mobile Hermes engine. Reduced to 20k — still sufficient for the local-device threat model where an attacker needs both the encrypted files and the password.

### Spinner timing

Modal buttons became unresponsive because `pbkdf2Async` started before React could re-render with the loading state. Fixed by setting `busy=true` synchronously, then deferring the heavy work with `setTimeout(fn, 50)` so the spinner paints first.

## Navigation fix

After journal creation, `setShowNewModal(false)` was racing with `router.push`. Reordered to: `refresh()` → close modal → navigate. Also captured `accessJournal.id` before setting state to null in unlock flow.

## Static imports restored

Dynamic `import()` for encryption/storage modules didn't resolve properly with Metro bundler. Reverted to static imports since the `expo-crypto` dependency was fully removed.
