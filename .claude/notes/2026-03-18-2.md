# v0.11.2 — Attachment sync, cloud import improvements, and journal management

## Changes

### Attachment sync (engine + cloud import)

- `SyncEngine` now uploads and downloads attachment files alongside pages
  - `uploadPageAttachments()` reads local attachments (device-decrypted, password layer preserved) and uploads to GDrive `attachments/` folder
  - `downloadPageAttachments()` downloads from GDrive, saves locally (device encryption applied), and updates `att.path` to the new local URI
  - Called for every page upload/download in the sync loop
- Cloud import (`handleCloudJournalSelect` in `NewJournalModal`) now downloads all attachments before saving the journal locally
- Encryption layering preserved correctly: GDrive stores password-encrypted data without device encryption; each device applies its own device key on save

### Cloud import UX improvements

- Import modal now shows **all** remote journals instead of filtering out local ones
- Local journals shown as disabled rows with check-circle icon and "Already on this device" label (uses existing `journalAlreadyLocal` i18n key)
- Added `paddingHorizontal` and `justifyContent: 'flex-start'` to cloud journal list items to fix margin issues

### Account modal — Manage Journals

- Added "Manage journals" button to account popover (between email and sign-out)
- New full modal listing all remote journals from GDrive registry
- Each row shows journal title, local availability badge, and a delete (trash) icon
- Delete triggers a confirmation modal warning that deletion is permanent and won't affect local copies
- After remote deletion, local copy (if any) has sync automatically disabled (`syncProvider: undefined`, `remoteSync: false`, `autoSync: false`)
- Added `deleteJournal()` to `RemoteStore` interface and `GDriveRemoteStore` implementation (deletes journal folder + removes registry entry)

### i18n

- Added 4 new keys across all 8 languages: `manageJournals`, `deleteRemoteJournal`, `deleteRemoteConfirm`, `deleteRemoteSuccess`

## Files modified

- `src/lib/sync/engine.ts` — attachment upload/download helpers + integration into sync loop
- `src/lib/sync/types.ts` — added `deleteJournal()` to `RemoteStore` interface
- `src/lib/sync/gdrive/store.ts` — implemented `deleteJournal()`
- `src/components/home/NewJournalModal.tsx` — cloud import attachment download + show all journals with local badge
- `src/components/home/AccountButton.tsx` — manage journals modal + delete confirmation + auto-disable local sync
- `src/i18n/dictionaries.ts` — new i18n keys for journal management
