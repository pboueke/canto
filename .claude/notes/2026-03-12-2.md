# 2026-03-12 - Android Build Setup

## What was done

Set up the Android build environment for running the app on an emulator.

### Environment configuration

- Added `ANDROID_HOME`, `JAVA_HOME`, and `PATH` exports to `~/.zshrc`
  - `JAVA_HOME=/snap/android-studio/current/jbr` (JDK 21 bundled with Android Studio snap)
  - `ANDROID_HOME=$HOME/Android/Sdk`
- Created `android/local.properties` with `sdk.dir` pointing to the SDK

### Build issues found and fixed

- **foojay-resolver 0.5.0 incompatible with Gradle 9**: The `@react-native/gradle-plugin` bundles foojay-resolver-convention v0.5.0 which references `JvmVendorSpec.IBM_SEMERU`, removed in Gradle 9. Fix: patch `node_modules/@react-native/gradle-plugin/settings.gradle.kts` to use version `1.0.0`. This patch is needed after every `npm install`.
- **JAVA_HOME not set**: Gradle wrapper requires `JAVA_HOME` in the environment. Resolved by adding to `~/.zshrc`.
- **ANDROID_HOME not found by Gradle**: Resolved by both env var and `android/local.properties`.

### To build and run on Android emulator

```bash
# 1. Source env vars
source ~/.zshrc

# 2. Patch foojay plugin (needed after npm install)
sed -i 's/foojay-resolver-convention").version("0.5.0")/foojay-resolver-convention").version("1.0.0")/' node_modules/@react-native/gradle-plugin/settings.gradle.kts

# 3. Start emulator from Android Studio Device Manager

# 4. Build and run
npx expo run:android
```
