# v0.15.0 — Credible Launch: onboarding, security docs, store listing, landing page

## Pre-commit hook version sync bug

The existing pre-commit hook (`.husky/pre-commit`) had a bug: it used `$PKG_VERSION` (from package.json) as the sed search pattern when updating app.json. Once app.json drifted to 0.11.3 while package.json was at 0.14.x, the sed couldn't find the pattern and silently failed — the drift became permanent.

**Fix**: Each file now reads its own version independently. build.gradle sync was also added (versionName + auto-increment versionCode).

## Onboarding flow

New route at `app/onboarding.tsx` with 4 screens: Welcome (Logo), Encryption (shield icon), Privacy (eye-off icon), Get Started (book-open). Button-driven navigation with slide animation (200ms, no swipe library needed). Skip marks as done. Completion navigates to home with `?fromOnboarding=true` query param that auto-opens NewJournalModal.

The onboarding check lives in `app/index.tsx` — reads AsyncStorage on mount, redirects to `/onboarding` if flag not set. Returns `null` until check completes to prevent flash.

i18n strings added to all 8 dictionaries (en, pt, es, de, fr, ru, zh, it) with 11 keys each in the new `onboarding` section of the Dictionary interface.

9 tests cover: screen rendering, navigation with animations (fake timers + advanceTimersByTime), AsyncStorage flag write, skip behavior, content assertions, icon rendering, and error handling (storage write failure).

## Security & privacy documentation

SECURITY.md expands the README's security section into a comprehensive whitepaper: threat model (what Canto protects against and what it doesn't), two-tier encryption details, ciphertext format, key management, session security, backup encryption, storage, data collection, and crypto dependencies.

PRIVACY.md is the privacy policy required by Play Store. Key finding during review: the sync engine strips device-key encryption before uploading to Google Drive (since the device key can't transfer to another device). Only password-layer encryption survives. Both documents were corrected to accurately describe this behavior.

## Landing page

Static HTML+CSS at `docs/index.html`, no JavaScript. Four pillars: encrypted at rest, not AI training data, open source, data portability. Privacy policy hosted at `docs/privacy.html` for Play Store URL requirement. Ready for GitHub Pages.
