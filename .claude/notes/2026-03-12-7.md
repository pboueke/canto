# Requirement #3: Filesystem & Data Layer

## What was done

### Security review & plan update

- Replaced `crypto-js` (unmaintained, CBC-only) with `@noble/ciphers` + `@noble/hashes` (Cure53-audited)
- Changed from AES-CBC to **AES-256-GCM** (authenticated encryption)
- Increased PBKDF2 iterations from 10,000 to **600,000** (OWASP 2023 minimum)
- Added unique 12-byte nonce per encryption, key zeroing, CSPRNG salt generation
- Ciphertext format: `base64([12-byte nonce][ciphertext][16-byte GCM tag])`

### Phase 1: Data Models (`src/models/`)

- `types.ts` — Journal, JournalContent, Page, PagePreview, Comment, Attachment, GeoLocation, Filter, JournalSettings
- `index.ts` — Re-exports

### Phase 2: Encryption (`src/lib/encryption/`)

- `types.ts` — EncryptionProvider, PasswordEncryptionProvider, EncryptionService interfaces
- `utils.ts` — AES-256-GCM encrypt/decrypt, salt generation, base64 encoding
- `device.ts` — Device-level encryption using expo-secure-store for key storage
- `password.ts` — PBKDF2-SHA256 key derivation (600k iterations) + AES-256-GCM
- `index.ts` — Unified service: device encryption always on, password encryption layered on top for secure journals

### Phase 3: Local Storage (`src/lib/storage/`)

- `types.ts` — LocalStore interface (CRUD for journals, pages, attachments)
- `local.ts` — Implementation using new expo-file-system API (Paths, File, Directory classes)
- `index.ts` — Exports

### Phase 4: Remote Sync Interface (`src/lib/sync/`)

- `types.ts` — RemoteStore interface, SyncResult, SyncConflict, RemoteJournalMeta
- `engine.ts` — SyncEngine with last-write-wins strategy, soft-delete propagation
- `index.ts` — Exports

### Phase 5: Integration hooks (`src/hooks/useStorage.ts`)

- useJournals, useJournal, usePage, useSavePage hooks wrapping LocalStore

### Phase 6: Tests (`src/lib/__tests__/`)

- `encryption.test.ts` — 13 tests: roundtrip, unique nonces, wrong key/password/salt rejection, tampering detection, unicode, large text
- `sync.test.ts` — 10 tests: upload/download/skip/delete scenarios, deletion propagation, non-existent journals

### Dependencies added

- `expo-file-system`, `expo-secure-store`, `expo-crypto`
- `@noble/ciphers`, `@noble/hashes`
- `uuid`, `@types/uuid`

### Config changes

- `jest.config.js` — Added transformIgnorePatterns and moduleNameMapper for @noble ESM packages
