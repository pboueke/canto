# 2026-03-12 — Requirement 5: Entries (Pages)

## What was done

Implemented the full entry system for canto (requirement 5). This includes:

### Data model updates

- `Attachment` gained `encrypted: boolean` field for mixed encrypted/non-encrypted attachments
- `Comment` gained `id: string` (UUID) for edit/delete targeting
- `PagePreview` gained `firstImage?: string` for journal list thumbnails

### Storage layer

- Encrypted attachment file naming uses `e` prefix (`eimg-`/`efl-`)
- `saveAttachment()`/`getAttachment()` accept optional `derivedKey` for password-layer encryption

### New hooks

- `useCreatePage`, `useDeletePage`, `useJournalTags`, `useAttachment`

### New components

- `ImageCarousel` — horizontal with dots, fullscreen viewer, edit mode arrows, encrypted variant
- `FileRow` — grid with extension badges, open/share, lock icon for encrypted
- `LocationTag` — pill with coords, maps link, clipboard copy
- `TagEditor` — tag management with journal-wide suggestions popup
- `CommentList` + `CommentModal` — add/edit/delete comments
- `AddAttachmentPopup` — FAB + modal popup with 6 attachment options
- `PageContent` updated with markdown rendering

### Screen changes

- `app/page/[id].tsx` — full rewrite with edit/preview, all attachments, save/delete
- `app/journal/[id].tsx` — FAB creates page, useFocusEffect refresh
- Removed welcome page auto-creation

### UI polish

- All emojis replaced with Feather icons throughout the app
- File preview now shows file size (B/KB/MB)
- First unencrypted image shown as thumbnail in journal page list
- Tag remove X is colored and inside the tag pill
- Geo tag X is inside the tag, geo tag is centered
- Standardized margins across all page components
- Save/confirm FAB is green, + FAB and tag add button are yellow
- Page layout: tags → images → encrypted images → geo tag → files → text body → comments
- Files and encrypted files displayed on same row
- "Decrypting..." label hides after encrypted images finish loading
- Page preview shows only first line of text
