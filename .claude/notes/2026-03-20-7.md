# v0.17.1 — Critical data-corruption fixes

Addresses all 5 CRITICAL issues from the codebase audit (`.claude/notes/2026-03-20-6.md`).

## Changes

### 1. Store initialization race condition (issue #1)

- `src/hooks/useStorage.ts` — replaced `initialized` boolean flag with `initPromise` Promise guard
- Concurrent `ensureInitialized()` callers now await the same promise instead of racing through the boolean check
- Promise resets on failure to allow retry

### 2. Device key creation race condition (issue #2)

- `src/lib/encryption/device.ts` + `device.web.ts` — wrapped `getOrCreateDeviceKey()` in `keyCreationPromise` guard
- `clearKey()` and `rotateKey()` both reset the promise so the next key read goes to storage
- Exported `_resetKeyCreationPromise()` for test isolation (4 test files updated)

### 3. Silent sync page download failures (issue #3)

- `src/lib/sync/types.ts` — new `DownloadResult` / `DownloadFailure` types; `downloadJournalMeta` return type changed from `JournalContent | null` to `DownloadResult | null`
- `src/lib/sync/gdrive/store.ts` — collects per-page failures from `Promise.allSettled` into structured `failures` array instead of `console.warn`
- `src/lib/sync/engine.ts` — unwraps `DownloadResult.content` for sync logic
- `src/components/home/NewJournalModal.tsx` — cloud import path shows `DataIntegrityWarningModal` on partial failures with Retry / Cancel actions

### 4. Import attachment error handling (issue #4)

- `src/lib/backup/import.ts` + `import.web.ts` — each `saveAttachment()` wrapped in try-catch; errors collected in `AttachmentError[]`; import completes with successful attachments and returns error list
- `src/components/home/NewJournalModal.tsx` — shows `DataIntegrityWarningModal` after import if attachments failed, explaining the problem and suggesting re-import

### 5. Validation accepts NaN/Infinity (issue #5)

- `packages/canto-data/src/validation.ts` — `checkNumber()` now rejects `NaN`, `Infinity`, `-Infinity` with `Number.isFinite()` check

### New component: DataIntegrityWarningModal

- `src/components/common/DataIntegrityWarningModal.tsx` — reusable modal for data integrity warnings with warning icon, description, scrollable details list, suggestion box, and configurable action buttons
- Added `dataIntegrity` i18n section (10 keys x 8 languages)

## Test coverage
