# 2026-03-13 Note 1 — Theming, Languages, Password Fix & UI Polish

## Changes

### Theme system expansion (6 themes)

- Added 4 new themes to `src/styles/themes.ts`: Monokai (dark, warm accents), Solarized Light (cream/blue), Nord (arctic blue-gray), Dracula (purple/pink/cyan)
- Introduced `ThemeName` union type and `isDark` boolean on `CantoTheme` interface

- Theme persistence updated to handle any theme name (was hardcoded for light/dark)
- Created `ThemePickerModal` component with miniature color previews (header dots, sidebar, text lines) and active indicator

### Language system expansion (8 languages)

- Added 6 full dictionaries: Spanish (es), German (de), French (fr), Russian (ru), Chinese (zh), Italian (it)
- Expanded `LangCode` type and exported `langCodes` array and `langNativeNames` map
- Created `LanguagePickerModal` component showing native language names with active indicator
- Updated `_layout.tsx` to load any saved language (was hardcoded for pt)

### InfoBox updated

- Theme button now shows current theme name and opens `ThemePickerModal`
- Language button now shows native language name and opens `LanguagePickerModal`
- Removed direct toggle behavior

### Password validation bug fix

- Bug: wrong password caused navigation to journal screen which showed "Journal not found"
- Root cause: PBKDF2 always succeeds (derives a wrong key), `handleUnlock` never caught an error
- Fix: added trial decryption via `tryLoadJournal()` after key derivation — if decryption fails, clears bad key and shows "Wrong password" without navigating
- Added `tryLoadJournal` export to `useStorage.ts`

### Journal card redesign

- Badges moved to top row, centered
- Icon increased 50% (28 → 42), centered
- Title below icon, centered
- Card height increased to 130

### Per-journal theme override

- Added `themeOverride?: string` to both `JournalSettings` and `Journal` interfaces
- Theme override synced to journal index on save for home screen access
- `JournalSettings` component: added theme picker row in display settings
- `journal/[id].tsx`: wraps content in `ThemeContext.Provider` with override theme
- `page/[id].tsx`: receives `themeOverride` as URL param, wraps content in override provider
- `JournalCard`: applies journal-specific theme to card preview on home screen
- `NewJournalModal`: includes theme picker with "Use global theme" option at creation time

### Full-screen NewJournalModal

- Replaced centered overlay modal with full-screen `Modal` (slide animation)

### Icon picker expansion
