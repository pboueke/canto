# v0.17.6 — UI fixes, i18n expansion, onboarding and auto-lock improvements

## Carousel centering fix (web)

- Root cause: `IMAGE_WIDTH` was computed from `Dimensions.get('window').width` (viewport), but the app container has `maxWidth: 1200px` on web — images overflowed.
- Fix: replaced static `SCREEN_WIDTH` with `onLayout`-based measurement of the actual container width.

## Download button visibility (web)

- Changed from `theme.colors.surface` background (invisible against images) to `rgba(0,0,0,0.4)` with white icon, 36px size.

## Portuguese/Spanish/French/German diacritics

- All four languages were missing accents throughout (ã, ç, é, ñ, ü, etc.). The `onboarding` section in PT was correct — rest was not.
- Fixed `langNativeNames`: Português, Español, Français.

## 12 new languages

- Added: ja, ko, ar, hi, tr, nl, pl, sv, vi, th, id, uk (total now 20).
- Translations in separate modules (`new-langs-1.ts`, `new-langs-2.ts`) imported into `dictionaries.ts`.
- RTL layout for Arabic is not in scope — just translations.

## Onboarding redirect loop fix (web)

- `AsyncStorage` (backed by `localStorage`) can silently fail on web (private mode, storage restrictions).
- Added three-layer defense: in-memory flag > direct `localStorage` > `AsyncStorage`.
- In-memory flag prevents redirect loops within a session even if all storage fails.

## Auto-lock improvements

- Default changed from 5m to 15m.
- Added actual user inactivity tracking via `onStartShouldSetResponderCapture` on the root View — `touchActivity()` is now called on every touch.
- Added `onAutoLock` subscription pattern to `JournalKeyContext`.
- New `AutoLockModal` component shows a warning dialog when auto-lock triggers, explaining the session was locked due to inactivity, then redirects to home on dismiss.
