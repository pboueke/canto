# Plan 19 — Per-journal Calendar page + anniversary filter (2026-04-14)

## What shipped

1. **Anniversary filter** — pages dated the same UTC month+day as today (prior years only). Activated from the Calendar page; visible as a banner on the journal screen when active; cleared by the existing filter-bar clear button.
2. **Calendar button** in `JournalHeader` (left of sync) → new per-journal calendar screen.
3. **Calendar screen** — journal-titled header, anniversary row (with 0/1/n copy), and a scroll of month cards. Each month shows days with pages highlighted.
4. **Scroll preservation** — session-scoped ref map per journal id. Restored on remount. Not persisted.

## Architecture

- **Route restructure**: `app/journal/[id].tsx` → `app/journal/[id]/index.tsx`; new sibling `app/journal/[id]/calendar.tsx`. Expo Router resolves `/journal/{id}` to the index, so no external links break.
- **Filter plumbing**: `useFilter` extended with `anniversary: boolean` (hook-local — `canto-data`'s `Filter` type untouched) and an `initial` param. The journal screen reads `?anniversary=1` / `?dateStart=...` / `?dateEnd=...` **once** on mount and seeds initial filter state.
- **Scroll context**: `CalendarScrollProvider` stores `{ [journalId]: number }` in a `useRef` map — no re-renders on scroll writes.
- **Pure helpers** (`src/lib/calendar.ts`): `getAnniversaryPages`, `getMonthsWithPages`, `monthRange`. All UTC-based; Feb-29 surfaces only on actual Feb-29s.

## Manual QA checklist (pending user verification)

- Calendar button appears on journal header; tapping opens calendar page.
- Scroll halfway, navigate to a page, back, back to calendar — offset restored.
- Tap a month card → journal filters to that month's date range.
- Tap anniversary row with count > 0 → journal shows anniversary banner and filters to prior-year same-day pages.
- Tap anniversary row with count === 0 → no navigation.
- `clearFilters` in FilterBar clears anniversary too.
- Dark + light themes render highlighted days with adequate contrast.
- RTL languages (ar, hi) — title truncation via `numberOfLines={1}`.
