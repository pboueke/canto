# v0.17.0 — UI refinements, first schema migration, accessibility

Requirement 17 implementation across 8 phases:

## Bug fixes

- **Encrypted image disappearing**: `ImageCarousel.tsx` useEffect dependency changed from `activeImages.length` to a stable key (`activeImages.map(img => img.id).join(',')`) — prevents cancelAll from wiping loaded state on edit→save cycles
- **Cloud import UUID**: `NewJournalModal.tsx` — conflict detection changed from title-based (`cloudLocalTitles.has(rj.title)`) to UUID-based (`cloudLocalIds.has(rj.id)`), added `existingIds` prop

## Features

- **Image download button**: New `downloadAttachment.ts` / `.web.ts` utility extracted from `handleOpenFile`, download overlay on carousel images in view mode
- **Image scaling**: `resizeMode="cover"` → `"contain"` with surface background
- **Thumbnail 80→120**: Both generation (`thumbnail.ts`) and display (`PageListItem.tsx`)
- **Full-text search**: Added `searchText` field to `PagePreview` (full text + tags lowercased), `useFilter` searches against it instead of just `previewText`
- **Search debounce**: 200ms debounce in `FilterBar.tsx` with cleanup on unmount
- **Help button**: Added to `InfoBox.tsx` beside version button, opens modal with GitHub Issues link
- **Accessibility**: `accessibilityLabel`/`accessibilityRole` added to ImageCarousel, FilterBar, FileRow, PageListItem, Card, InfoBox; new `a11y` i18n section (11 keys × 8 languages)

## Schema migration (first real use of migration framework)

- `SCHEMA_VERSION` bumped to `0.17.0`, legacy fallback set to `0.16.0`
- Created `v0_16_0_to_v0_17_0.ts` migration: strips `showMarkdownPlaceholder` from settings
- Removed `showMarkdownPlaceholder` from `JournalSettings` interface, `DEFAULT_JOURNAL_SETTINGS`, validation, JournalSettings UI toggle, and all 8 i18n dictionaries
- Updated `format.ts` legacy manifest default from `1.0.0` to `0.16.0`
- Updated `DATA.md` with migration history table and corrected version references

## Test coverage

- 29 new migration corruption-safety tests (`__tests__/migrations/v0_16_0_to_v0_17_0.test.ts`)
- New tests: ImageCarousel (download button), downloadAttachment (web), InfoBox (help modal), useFilter (full-text, tag search), pageToPreview (searchText)
- Updated: thumbnail (120px), migration chain tests, format tests, 13 test fixtures (showMarkdownPlaceholder removal)
- Total: 706 tests across 50 suites, all passing
