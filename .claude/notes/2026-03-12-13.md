# 2026-03-12 Note 13 — Password UX & Biometric Auth

## Changes

### Password change loading spinner

- Rewrote `ChangePasswordModal` to use the same `setTimeout` + full UI swap pattern as `NewJournalModal` and `JournalAccessModal`
- When busy, the entire form is replaced with a centered `ActivityIndicator` + progress text (re-encryption status)
- Previously only disabled buttons during processing with no visual feedback

### Password no-recovery warning

- Added warning with alert-triangle icon to both `NewJournalModal` and `ChangePasswordModal`
- Warning appears when a password is entered: "There is no password recovery. If you forget your password, your data will be permanently lost."
- i18n strings added for EN (`passwordWarning`) and PT (`passwordWarning`)

### Biometric authentication

- Created `src/lib/biometric.ts` with `isBiometricAvailable()` and `authenticateBiometric()` wrapping `expo-local-authentication`
- Added `biometric?: boolean` field to `Journal` interface in `src/models/types.ts`
- `NewJournalModal`: biometric toggle appears when device supports it, passed through to journal creation
- `JournalSettings`: biometric toggle in settings panel, saved to journal metadata
- `app/index.tsx`: biometric gate runs before journal access — prompts fingerprint/face before showing password modal (secure) or navigating (non-secure)
- `useCreateJournal`: accepts and persists `biometric` flag
- i18n strings: `biometricLock`, `biometricReason`, `biometricUnavailable` in EN and PT
