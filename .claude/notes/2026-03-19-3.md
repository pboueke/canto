# Web Platform Support (v0.14.0)

## Summary

Added full web platform support using Metro's `.web.ts` platform file resolution. The app now runs on `npx expo start --web` with IndexedDB-backed storage, localStorage device keys, and platform-appropriate handling for all native-only APIs.

## Architecture

- **Strategy**: Keep original `.ts` files as native defaults, add `.web.ts` overrides. Metro prefers `.web.ts` on web, falls back to `.ts` on native. TypeScript sees `.ts` for type-checking.
- **Storage**: `local.web.ts` implements the full `LocalStore` interface using IndexedDB with a single `files` object store keyed by virtual paths (e.g., `canto/{journalId}/pages/{pageId}.json`).
- **Device encryption**: `device.web.ts` stores the device key in `localStorage` (with console security warning) instead of `expo-secure-store`.
- **No changes** to the `LocalStore` interface, hooks, sync engine, or any consumers.
