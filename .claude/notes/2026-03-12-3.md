# 2026-03-12 - Dependency Fixes & Expo Go Compatibility

## What was done

### Downgraded to Expo SDK 54

- Expo Go on the Play Store supports SDK 54, not 55
- Ran `npx expo install expo@^54.0.0 --fix` to downgrade all Expo packages
- Key version changes:
  - expo: ~55.0.6 -> ^54.0.0
  - react: 19.2.0 -> 19.1.0
  - react-native: 0.83.2 -> 0.81.5
  - expo-router: ~55.0.5 -> ~6.0.23
  - jest: ~30.3.0 -> ~29.7.0
  - jest-expo: ~55.0.9 -> ~54.0.17

### Removed eslint-plugin-react

- Incompatible with ESLint 10 (peer dep caps at ^9.7)
- Was not used in eslint.config.mjs anyway (removed earlier due to API incompatibility)
- Also removed eslint-plugin-react-hooks for the same reason

### Added Makefile

- `make install` — npm install + auto-patch foojay plugin
- `make patch` — patches foojay-resolver 0.5.0 -> 1.0.0 for Gradle 9
- `make emulator` — launches first available AVD
- `make android` / `make ios` — patches then builds
- `make start` — starts Expo dev server (use with Expo Go)
- `make web` — starts web dev server
- `make check` — lint + typecheck + tests
- `make clean` — removes generated native folders and build output

### Android emulator issues

- GPU/graphics errors on Linux with default settings — use `-gpu swiftshader_indirect` or switch to Software rendering in AVD settings
- KVM may need to be installed for acceptable performance
- Recommended alternative: use Expo Go on a physical phone instead
