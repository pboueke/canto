# UI Cleanup Implementation (Requirement 12, v0.12.0)

## Summary

Implemented 7 UI improvements covering performance, UX, mobile fixes, developer tools, and branding. Follow-up fixes for hooks ordering, sync UX, dev menu bugs, and sync performance.

## Items Implemented

### 1. Encrypted Thumbnail Generation

- Created `src/lib/thumbnail.ts` — uses `expo-image-manipulator` to generate 80×80 JPEG thumbnails from base64 images
- Updated `app/page/[id].tsx` `handleSave` to generate thumbnail from first non-deleted image before saving
- Updated `src/components/journal/PageListItem.tsx` to prefer inline base64 thumbnail over the slow `enqueueThumbnail` flow
- Updated `src/models/types.ts` — added `thumbnail?: string` to `PagePreview`, updated `pageToPreview()`
- Thumbnails are stored inline in the Page JSON — encrypted alongside page data, synced and backed up automatically

### 2. Editable Page Date & Time

- Rewrote `src/components/page/PageHeader.tsx` — added `isEditing`, `onDateChange`, `dateValue`, `onBack` props
- When editing, date and time sections are wrapped in `Pressable` that opens `DateTimePicker` (date/time modes)
- Small edit icon hint shown next to date/time when editable

### 3. Discard Changes on Leave

- Added `BackHandler` listener for Android hardware back button in `app/page/[id].tsx`
- Added `navigation.addListener('beforeRemove', ...)` for navigation interception
- Added `handleBack` callback passed to `PageHeader` → `BackButton` via `onBack` prop
- `BackButton` now accepts optional `onBack` prop (falls back to `router.back()`)
- All three paths show the existing discard Alert when `isEditing && isDirty`

### 4. Android Navigation Bar FAB Fix

- Updated `FloatingActionButton.tsx` — imports `useSafeAreaInsets`, bottom offset is now `bottom + insets.bottom`

### 5. Scroll Pagination

- Created `src/hooks/usePagination.ts` — generic hook returning `{ visiblePages, loadMore, hasMore, reset }`
- Updated `app/journal/[id].tsx` — uses `usePagination(filteredPages, 15)`, passes to FlatList with `onEndReached` and footer spinner

### 6. Hidden Dev Menu

- Created `src/lib/devTools.ts` — 5 functions: `duplicateJournal`, `duplicatePage`, `generateBlankJournals`, `generateBlankPages`, `wipeAllData`
- Created `src/components/dev/DevMenu.tsx` — modal with journal/page pickers, count input, 4 action buttons, and wipe-all-data with double confirmation
- Updated `app/index.tsx` — logo wrapped in Pressable with 7-tap counter, passes `devUnlocked` to `InfoBox`
- Updated `src/components/home/InfoBox.tsx` — accepts `devUnlocked` prop, shows "Dev Menu" button in changelog modal

### 7. App Icon Generation Script

- Created `scripts/generate-icons.js` — Node.js script using `sharp` to generate all 6 icon assets from `src/assets/images/canto_bv1.png`
- Generated and replaced all icon assets in `assets/`

## Follow-up Fixes

- **Hooks order violation**: Moved `handleDateChange`/`handleBack` before early returns in PageScreen to comply with Rules of Hooks
- **Journal screen loading flash**: Changed loading guard to `loading && !journal` so background refreshes (sync, focus) don't flash a full-screen spinner
- **Dev menu page loading**: Added `ensureKey` helper that auto-derives encryption keys for non-secure journals before reading pages
- **Dev menu icon**: Changed blank journal icon from emoji `'📓'` to Feather name `'book'`
- **Wipe button contrast**: Uses solid `#c0392b` background with white text for readability on all themes
- **Cloud import progress bar**: GDrive journal import in NewJournalModal now shows progress bar tracking per-page attachment downloads
- **Import progress total**: Fixed overcounting — progress now tracks only the slow download phase, not the near-instant local saves
- **Parallel sync**: Attachment uploads/downloads in SyncEngine use bounded concurrency (4 workers)
- **Parallel GDrive downloads**: `downloadJournalMeta` page fetches use `Promise.all`; cloud import attachment downloads parallelized per page
