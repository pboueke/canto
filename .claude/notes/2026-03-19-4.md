# Web Feature Implementations & Fixes (v0.14.1)

## Summary

Addressed unsupported web features identified after v0.14.0. Replaced stubs with real implementations for backup export/import, added web date pickers, fixed geo links, and created a no-op Google Auth context for web.

## Changes

### Backup Export/Import — Real Web Implementations

- `export.web.ts` — full implementation using JSZip → Blob → `URL.createObjectURL()` → anchor download. Same encryption/progress/attachment logic as native, just different I/O.
- `import.web.ts` — full implementation using `fetch(blobUrl)` → `ArrayBuffer` → JSZip. Same decryption/ID-regeneration/attachment-rewrite logic as native.
- Removed the intermediate `ExportMenu` dropdown — header archive button now opens `ExportJournalModal` directly.
- Restyled `ExportJournalModal` to match `SyncModal` (same colors, gap spacing, progress bar, single action button + close pattern).

### DateTimePicker — Web Support

- `PageHeader.tsx` — hidden HTML `<input type="date">` and `<input type="time">` triggered via `.showPicker()` on web. Native `@react-native-community/datetimepicker` loaded via lazy `require()` only on non-web.
- `FilterBar.tsx` — same pattern for date range filter inputs.

### Google Auth — Web No-op Context

- `GoogleAuthContext.web.tsx` — provides same context shape with null user, false isSignedIn, no-op signIn/signOut. Never imports `@react-native-google-signin` (which throws on web). Logs warning on signIn attempt.
- `AccountButton` visible on web (shows "Connect Account") but signIn will show warning.
- Cloud sync features naturally hidden since `isSignedIn` is always false.

### Other Fixes

- `LocationTag.tsx` — uses `https://www.google.com/maps?q=lat,lng` on web instead of `geo:` scheme.
- `JournalHeader.tsx` — hides cloud/sync button on web.
- `webCompat.test.ts` — added `@react-native-google-signin/google-signin` to native-only modules check.

### Dependency Updates

- Updated 7 packages to Expo SDK 55 recommended patch versions (expo-constants, expo-linking, expo-location, expo-router, expo-sharing, expo-splash-screen, jest-expo).
