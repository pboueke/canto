# 20 — Editor styling and Android DEX optimization (v0.20.0)

Requirement: `.claude/requirements/20.styling_and_dex`. Plan: `.claude/plans/20.styling_and_dex.md`.

## What landed

### Journal editor and viewer

- The multiline editor uses a font-scale-derived 16-line minimum and grows or shrinks with content without nested scrolling.
- Web measurement preserves the caret, window scroll, and ancestor scroll offsets while resizing.
- Entering edit mode does not autofocus or open the keyboard.
- The inner `TextInput` is borderless on web and Android so focus decoration cannot overlap the caret or line-start text; the enclosing page-content card remains the visual boundary.
- Read mode has a font-scale-derived four-line minimum.
- Native sizing resets stale measurements when external content replaces the current page while preserving height through controlled local edits.

### Android release generation

- `expo-build-properties` enables release minification and resource shrinking.
- `plugins/withAndroidReleaseOptimization.js` selects `proguard-android-optimize.txt` and enables AGP 8.12 optimized resource shrinking.
- `plugins/withReleaseSigningConfig.js` generates environment-backed release signing without embedding secrets.
- `plugins/withCantoArchive.js` restores canonical Kotlin sources from `native/canto-archive/` and registers `CantoArchivePackage` after every clean prebuild.
- `plugins/withAndroidDebugApplicationId.js` gives debug builds the side-by-side package ID `com.boueke.canto.debug`; release remains `com.boueke.canto`.
- Brace-aware Gradle transformations fail closed when signing, ProGuard, or debug-package declarations move outside their intended build types.
- Generated Android Kotlin files are no longer tracked; `native/canto-archive/` and Expo config plugins are the sources of truth.

### Reproducible release build

- `scripts/build-android-release.sh` loads ignored credentials from `android_build.env`, defaults `NODE_ENV` to production, clean-prebuilds Android, validates generated signing/R8/native/version configuration, preserves `JAVA_TOOL_OPTIONS`, enables the JDK 25 native-access option, and builds `bundleRelease`.
- The script now requires non-empty `mapping.txt`, `usage.txt`, `configuration.txt`, and `seeds.txt`, verifies the AAB signature, and always removes the temporary copied keystore.
- `android_build.env.example` documents safe local setup; the real env file, keystore, Android project, and build outputs remain ignored.
- Version is `0.20.0`, Android version code is `27`.

## Remaining release acceptance

The code and local release evidence are complete. Before production rollout:

1. Upload the AAB to a Google Play internal track.
2. On a real device, smoke-test the optimized Play-delivered build: launch, open a journal, edit/save/reopen a multiline page, and import a native `.canto.zip` backup.
3. Confirm Play reports artifact `0.20.0` / code `27` and records optimization, obfuscation, and shrinking at or above 25%. If Play omits the DEX alert because the app is below 10 MiB uncompressed DEX, retain the local R8 evidence above and record any metrics Play does expose.
