# Requirement 7: Journal Management

## What was done

### Journal Settings Panel

- Created `JournalSettings.tsx` — full-screen settings panel replacing journal view when opened via cog icon
- Statistics section showing page count and creation date
- 7 display toggles: 24h time, preview tags/thumbnails/icons, filter bar, markdown tips, auto-location
- Sort order picker cycling through ascending/descending/none
- Change icon via existing IconPicker in a slide-up modal
- Change name via text input modal
- Change password with re-encryption flow: verifies old password, derives new key, re-saves all pages and metadata
- Delete journal with two confirmation modes: password for secure journals, type "delete {name}" for non-secure

### Filter Bar

- Created `FilterBar.tsx` — horizontal bar with search input, date range pickers, and property badges
- Created `FilterModal.tsx` — slide-up modal with attachment type toggle buttons and tag selection
- Created `useFilter.ts` hook — pure logic for filtering PagePreview arrays by query, date range, attachment properties, and tags
- All filters combine with AND logic; tags also use AND (entry must have all selected tags)
- Date filtering uses UTC-based day boundaries
- Filter bar visibility controlled by journal settings toggle

### Supporting Changes

- Added `useDeleteJournal` and `useSaveJournal` hooks to useStorage
- Added `hasComments: boolean` to PagePreview and pageToPreview
- Added `journalSettings` and `filterBar` i18n sections (EN/PT)
- Added `confirm` and `done` to common i18n
- Journal page list now respects `settings.sort` order
- Installed `@react-native-community/datetimepicker`
